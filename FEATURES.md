## Interview Demonstration Script

### Introduction (30 seconds)
> "VectorCraft is a web-based vector design tool I built using React and Paper.js. It allows users to create professional vector graphics with an intuitive interface similar to Figma or Canva, but entirely in the browser with no backend required—though I've prepared it for Firebase integration."

### Demo Flow (2-3 minutes)

**1. Show Welcome Screen (15s)**
> "The app starts with an engaging welcome screen showcasing the key features. Notice the glassmorphism effect and smooth animations—all custom CSS, no libraries."

**2. Enter Editor (10s)**
> "Once we start, you see the main workspace with a toolbar on the left, canvas in the center, and property/layer panels on the right."

**3. Draw Rectangle (15s)**
> "Let me select the rectangle tool and draw a shape. Notice the smooth creation and default gradient—I chose a purple gradient for a modern, professional feel."

**4. Show Properties (20s)**
> "Selecting the shape opens the properties panel where you can change colors, stroke width, opacity, rotation, and scale. All updates happen in real-time using Paper.js's powerful API."

**5. Add More Shapes (20s)**
> "Let me add a circle and use the pen tool for free-hand drawing. The pen tool automatically smooths the path for a professional result."

**6. Layer Management (15s)**
> "In the layers panel, you can see all objects. I can reorder layers, toggle visibility, or delete items. This was challenging to implement because I needed to sync Paper.js's internal layer system with React state."

**7. Export (15s)**
> "Finally, I can export as SVG for vector scalability or PNG for immediate use. The export system uses Paper.js's built-in export API and browser Blob API."

### Technical Deep Dive (Pick 1-2)

**Canvas Architecture:**
> "The canvas uses Paper.js, which provides a scene graph and drawing tools. I wrapped it in React using refs to avoid re-render issues. The zoom and pan system required careful event handling to feel smooth."

**State Management:**
> "State flows from App.jsx down to components. The canvas ref is shared across components for direct Paper.js manipulation. This hybrid approach—React for UI, Paper.js for canvas—required careful synchronization."

**Tool System:**
> "Each tool is a Paper.js Tool instance with onMouseDown, onMouseDrag, and onMouseUp handlers. I designed a clean factory pattern to switch tools without memory leaks."

**Design System:**
> "I built a comprehensive design system with CSS variables, glassmorphism effects, and a consistent color palette. The goal was to create something that feels premium and modern, suitable for a startup product."

### Closing (15s)
> "This project demonstrates my ability to build complex, interactive web applications with modern design, clean code architecture, and production-ready features. It's currently ready for enhancement with Firebase for cloud saving and user authentication."
