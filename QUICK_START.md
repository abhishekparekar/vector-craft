# 🎯 VectorCraft - Quick Start Guide

## 5-Minute Tutorial

### Step 1: Launch the Application
1. Open your terminal
2. Run `npm run dev`
3. Navigate to `http://localhost:5173`
4. You'll see a stunning welcome screen

### Step 2: Start Creating
1. Click **"Start Creating"** button
2. You're now in the main editor interface!

## Your First Drawing

### Draw a Rectangle
1. Click the **Rectangle** tool (square icon) in the left toolbar
2. Click and drag on the canvas
3. Release to create the rectangle
4. ✨ Your rectangle appears with a beautiful gradient!

### Customize Colors
1. Click the **Select** tool (arrow icon)
2. Click your rectangle to select it
3. In the **Properties Panel** (right side):
   - Change **Fill Color** - Click the color picker
   - Change **Stroke Color** - Customize the border
   - Adjust **Stroke Width** - Use the slider

### Add a Circle
1. Click the **Circle** tool
2. Click where you want the center
3. Drag outward to set the size
4. Release to create

### Free Drawing
1. Click the **Pen** tool
2. Draw freely on the canvas
3. The path automatically smooths for you!

### Add Text
1. Click the **Text** tool (T icon)
2. Click where you want text
3. Type your message
4. Customize in Properties Panel

## Working with Layers

### View Your Layers
- Check the **Layers Panel** (bottom right)
- Each object you create becomes a layer
- Layers show icons based on type:
  - ▭ Rectangle
  - ● Circle
  - ✎ Path
  - T Text

### Layer Controls
- **👁️ Eye Icon** - Show/hide layer
- **⬆️ Up Arrow** - Move layer forward
- **⬇️ Down Arrow** - Move layer backward
- **🗑️ Trash Icon** - Delete layer

---

## Navigation & View Controls

### Zoom
- **Mouse Wheel** - Scroll to zoom in/out
- **Zoom +/-** buttons in TopBar
- Zoom range: 10% to 1000%

### Pan
- **Hand Tool** - Click and drag to move around
- **Space + Drag** - Pan with any tool active

### Grid
- **Grid Button** in TopBar toggles the grid
- Helpful for alignment and spacing

---

## Editing Objects

### Select an Object
1. Click **Select** tool
2. Click any object on canvas
3. Properties Panel shows its settings

### Transform Properties

#### Colors
- **Fill Color** - Interior color
- **Stroke Color** - Outline color
- Both support hex codes (e.g., #667eea)

#### Stroke
- **Width** - 0 to 20px
- Slider for easy adjustment

#### Appearance
- **Opacity** - 0% to 100%
- Make objects transparent

#### Transform
- **Rotation** - 0° to 360°
- **Scale X/Y** - Stretch or shrink

### Moving Objects
1. Select an object
2. Click and drag to new position

## Saving Your Work

### Local Save
1. Click **Save Project** (💾 icon in TopBar)
2. Your project saves to browser storage
3. Visual feedback confirms save

### Load Saved Project
1. Click **Load Project** (📁 icon)
2. Your last project restores

### Export

#### Export as SVG
1. Click **SVG** button (top right)
2. Vector format - scales perfectly
3. Great for web and print

#### Export as PNG
1. Click **PNG** button (top right)
2. Raster image format
3. Ready to share anywhere

## Pro Tips 💡

### Design Tips
1. **Start with simple shapes** - Combine rectangles and circles
2. **Use gradients** - The default colors are pro-quality
3. **Layer organization** - Keep layers named and organized
4. **Grid alignment** - Enable grid for precise layouts

### Workflow Tips
1. **Save frequently** - Click save after major changes
2. **Experiment freely** - You can always reload
3. **Use keyboard shortcuts** - Space for pan is faster
4. **Zoom in for details** - Get precise with high zoom

### Performance Tips
1. **Clean up unused layers** - Delete what you don't need
2. **Simplify paths** - Pen tool auto-simplifies, but be mindful
3. **Work at 100% zoom** - Easier on your system

## Troubleshooting

### "Tool not working"
- Make sure the correct tool is selected (highlighted in purple)
- Try clicking the tool again

### "Can't select object"
- Switch to Select tool (arrow icon)
- Make sure object isn't hidden in layers

### "Properties not updating"
- Ensure object is selected (check selection highlight)
- Try re-selecting the object

### "Canvas is blank"
- Check if layers are visible (eye icon)
- Try zooming out (might be zoomed in too far)

### "Can't export"
- Make sure you've drawn something first
- Check browser allows downloads
